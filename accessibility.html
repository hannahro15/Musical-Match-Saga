Accessibility Statement

Last updated: 18 November 2026

This statement describes the accessibility of the Musical Match Saga web game. The aim is for the game to meet the Web Content Accessibility Guidelines (WCAG) 2.2 at level AA.

In short: the game has not been formally tested for accessibility, and it does not yet meet WCAG 2.2 AA. Some accessibility features are built in, and there are known problems that are still being worked on.

What the game includes

  • Keyboard play: the buttons and the board tiles can be reached with the Tab key, and a focused tile can be selected and swapped with Enter or Space. The game also works with a mouse and touch.
  • Screen reader announcements: the game announces matches, combos, level results and some other changes through a live region, and each tile has a label giving its symbol, row and column.
  • Reduced motion: animations and transitions are shortened when your device is set to reduce motion.
  • Decorative emoji: emoji used only for decoration are hidden from screen readers.
  • Without JavaScript: the game needs JavaScript. If it is turned off, the page shows a message saying so.

What has been tested

No formal accessibility testing has been done. The game has not been tested with a defined set of browsers and assistive technologies, and has not been audited against WCAG 2.2. A manual check with a keyboard and screen readers is planned, tracked in issue 60. This page will be updated with the results when they are available.

Known problems

Known accessibility problems are tracked as open issues with the accessibility label on GitHub. They include, for example, that you cannot yet move between tiles with the arrow keys, keyboard focus is not yet kept inside open dialogs, and screen readers may announce more than is needed during play. That list is the most up-to-date source.

Report a problem

If you find something that does not work for you, please open an issue on the project's GitHub repository. It helps to say what device, browser and assistive technology you use, what you tried and what happened.
